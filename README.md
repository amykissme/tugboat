# Мини-приложение «Знакомства» для Telegram

Чёрно-красный интерфейс, нижняя панель: **Профиль / Оценка / Подписка** (активная вкладка подсвечивается красным).

## Структура
- `index.html` — всё мини-приложение (HTML + CSS + JS в одном файле)
- `.nojekyll` — чтобы GitHub Pages отдавал файлы как есть
- `bot/bot.py` — пример бота (python-telegram-bot): приём анкет, оплата подписки Telegram Stars
- `bot/requirements.txt`

## Запуск
1. Создайте публичный репозиторий на GitHub и загрузите в корень `index.html` и `.nojekyll`.
2. Settings → Pages → Source: ветка `main`, папка `/ (root)`. Получите адрес `https://ЛОГИН.github.io/РЕПО/`.
3. В @BotFather: `/newbot` (если бота нет), затем `/mybots` → ваш бот → Bot Settings → Menu Button → вставьте адрес.
4. Запустите бота:
   ```
   cd bot
   pip install -r requirements.txt
   BOT_TOKEN=токен WEBAPP_URL=https://ЛОГИН.github.io/РЕПО/ python bot.py
   ```
5. Откройте бота, отправьте `/start` и нажмите кнопку «Открыть приложение».

## Как это работает
- Анкета и оценки хранятся локально на устройстве (`localStorage`).
- Кнопка «Отправить анкету в бот» передаёт данные боту через `Telegram.WebApp.sendData` (без фото, лимит 4096 байт). Бот сохраняет их в `profiles.json`.
- Подписка: приложение отправляет боту запрос, бот выставляет счёт в Stars, после оплаты открывает приложение со ссылкой `?plan=premium`.
- Вне Telegram (в браузере) работает демо-режим.

## Что нужно доработать для боевого запуска
- Анкеты для оценки сейчас демо-список `DEMO` в `index.html`. Нужен сервер/БД, которые отдают реальные анкеты и принимают оценки (с проверкой `Telegram.WebApp.initData` на сервере).
- Фото анкет нужно хранить на сервере (S3, Cloudflare R2 и т. п.).
- Подписку и лимиты нужно хранить и проверять на сервере, иначе их можно обойти на клиенте.
- Для 18+ добавьте условия использования и модерацию анкет.
